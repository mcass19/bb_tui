## drive
Hold-to-drive. The arrow keys set a throttle (up/down) and a turn
(left/right) of -1, 0 or 1, scaled by `throttle_scale` and
`turn_scale`; while one is held, bb_tui calls `publish` at `rate` Hz,
and calls `stop` when it is let go.




### Examples
```
drive do
  publish {MyKit.Drive, :command}
  stop {MyKit.Drive, :stop}
  turn_scale param([:yaw, :turn_rate])
end

```




### Options

| Name | Type | Default | Docs |
|------|------|---------|------|
| [`publish`](#drive-publish){: #drive-publish } | `{atom, atom}` |  | `{module, function}` called as `function(robot, throttle, turn)` on every tick. |
| [`stop`](#drive-stop){: #drive-stop } | `{atom, atom}` |  | `{module, function}` called as `function(robot)` when driving stops. |
| [`throttle_scale`](#drive-throttle_scale){: #drive-throttle_scale } | `number \| BB.TUI.Extension.Source` | `1.0` | Multiplies the throttle: a number, or a `param(path)` read when driving starts. |
| [`turn_scale`](#drive-turn_scale){: #drive-turn_scale } | `number \| BB.TUI.Extension.Source` | `1.0` | Multiplies the turn: a number, or a `param(path)` read when driving starts. |
| [`rate`](#drive-rate){: #drive-rate } | `pos_integer` | `20` | Ticks per second while a drive key is held. |
